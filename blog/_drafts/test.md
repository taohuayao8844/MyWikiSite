# 博客文章支持功能说明

本文用于整理当前网站博客文章**已经支持**或**可直接使用**的功能，便于后续写文章时快速查阅。

---

## 1. 文章基础信息（Front Matter）

博客文章顶部可以使用 Front Matter 配置文章元信息，常见支持项如下：

```md
---
title: 文章标题
description: 文章简介
slug: 自定义链接
authors: 默认作者
tags: [分类1, 分类2, 标签3]
date: 2026-03-29
image: /img/xxx.png
hide_table_of_contents: false
---
```

### 已支持字段说明

#### 1. `title`
- 作用：文章标题
- 用途：显示在文章页标题、博客列表、搜索结果等位置
- 示例：

```md
title: 如何高效整理知识库
```

#### 2. `description`
- 作用：文章摘要 / 简介
- 用途：用于 SEO、列表摘要、分享卡片等场景
- 示例：

```md
description: 记录如何用 Docusaurus 搭建个人知识网站。
```

#### 3. `date`
- 作用：文章发布日期
- 用途：显示文章时间、参与文章排序
- 示例：

```md
date: 2026-03-29
```

#### 4. `tags`
- 作用：文章标签
- 用途：可用于**分类、专题归档、标签聚合**
- 说明：当前博客系统没有单独的 `category` 字段，通常使用 `tags` 来实现“分类”效果
- 示例：

```md
tags: [博客搭建, Docusaurus, 前端]
```

#### 5. `slug`
- 作用：自定义文章访问路径
- 用途：让文章链接更短、更稳定、更易读
- 示例：

```md
slug: /build-blog-with-docusaurus
```

#### 6. `authors`
- 作用：指定文章作者
- 用途：在多人写作或后续扩展作者页时有用
- 示例：

```md
authors: default
```

#### 7. `image`
- 作用：文章封面图 / 分享图
- 用途：社交分享、搜索引擎预览、文章视觉增强
- 示例：

```md
image: /img/blog-cover.png
```

#### 8. `hide_table_of_contents`
- 作用：是否隐藏右侧目录
- 用途：适合短文、公告类文章
- 示例：

```md
hide_table_of_contents: true
```

## 2. 当前网站已启用的博客能力

根据当前站点配置，博客文章已经支持以下功能。

### 2.1 标题显示
- 支持文章标题显示
- 标题可参与页面展示与搜索结果展示

### 2.2 日期显示
- 支持文章发布日期显示
- 可作为文章排序依据

### 2.3 标签 / 分类
- 支持 `tags`
- 当前可把 `tags` 当作“分类”使用
- 一篇文章可配置多个标签

### 2.4 阅读时长
- 当前配置中已开启：

```js
blog: {
  showReadingTime: true
}
```

- 页面会显示文章预计阅读时间

### 2.5 编辑链接
- 当前配置中已开启：

```js
editUrl: 'https://github.com/taohuayao8844/taohuayao8844.github.io/tree/main/'
```

- 可在文章页显示“编辑此页”相关入口，便于维护

### 2.6 数学公式
- 当前博客已启用：
  - `remark-math`
  - `rehype-katex`

- 支持在文章中写 LaTeX 数学公式

#### 行内公式
```md
这是一个行内公式：$E = mc^2$
```

#### 块级公式
```md
$$
\int_a^b f(x)\,dx
$$
```

### 2.7 Markdown / MDX 内容
- 支持 Markdown 编写文章
- 可使用常见 Markdown 能力：
  - 标题
  - 列表
  - 引用
  - 表格
  - 代码块
  - 图片
  - 链接

### 2.8 代码高亮
- 站点已配置 Prism 代码高亮主题
- 文章中的代码块会自动高亮显示

示例：

```md
```js

```
```

### 2.9 文章目录（TOC）
- 当前站点已启用目录能力
- 目录默认基于二级到五级标题生成：

```js

  maxHeadingLevel: 5,

- 也可以用 `hide_table_of_contents: true` 对单篇文章隐藏目录

### 2.10 本地搜索
- 当前站点已启用本地搜索插件，并且已索引博客内容：

```js

- 博客文章标题、正文内容可被站内搜索检索到

### 2.11 SEO 基础描述
- 站点已配置全局 description

## 4. 当前博客更适合这样理解“分类”

如果你想给文章加“分类”，当前最推荐的做法是直接使用：

```md
tags: [学习笔记, 嵌入式, 博客搭建]
```

原因：
- 当前配置里没有单独看到 `category` 字段的专门配置
- Docusaurus 博客默认更偏向使用 `tags`
- `tags` 同时能承担“分类 + 标签”的作用

也就是说：

- **标题**：`title`
- **日期**：`date`
- **分类**：建议使用 `tags`
- **摘要**：`description`
- **封面**：`image`
- **自定义链接**：`slug`
