# 什么是第二课堂学分

> [!IMPORTANT]
>
> 1. 二课需要提交纸质版佐证材料，所以学生在打印的时候请在右上角写上姓名、学号，并将自己的名字用颜色笔标出来；
> 2. 系统上传电子版的截图的时候，尤其是三创、图书馆这种学生名字众多情况，务必将自己的名字框起来，否则不予通过；
> 3.英语四级是0.5分、六级是0.5分，加起来一共是1分，这点是要注意下；
> 4.导师制通过后是一个项目加一分，上传证明材料，申报项目是科研活动--个人自立题；（各系开具第二课堂加分证明）
> 5.申报项目要写清楚项目，如全国大学生数学竞赛、大英赛等；资格证书——驾照/普通话证等；
> 6.二课的分数达到毕业要求即可，分数超过太多也无意义。且不能重复申请，之前审核通过的如驾照，就不能二次申请；本学年所取得奖励，务必当年内申请，逾期将不予通过。

**毕业有5分就行，很好获取，并不是很困难**
