# 为什么做这些整理

记得我刚大二的时候，机缘巧合下访问到了[写在前面 | 万工笔记](https://www.indratang.top/s1/zero2hero)这个浙大学长开源的博客，里面的介绍远远比老旧的课本要新，要更加吸引我，我也跟着他的视频一步步搭建了我的网站（开始的框架已经被废弃了--Astro 架构），我在想怎么会有这样无私的学长，仿佛在迷茫的大学航线中，立起了一座又高又亮的灯塔，虽然现在我已经摆烂了，没有读研的欲望，开始了实习的生活，正好闲下来了，加上又看见了[Home - Power's Wiki](https://wiki-power.com/)这位巨佬的博客，记录自己的生活，分享自己的见解，我又捡起来了这个许久未更新的网站，并更新框架（docusaurus框架），希望能帮助到后来的学弟。

我的大学可以说是丰富的，大部分的比赛我都参与过了，感觉也算是不虚此行。

我知道，我所说的是远远不够完善、不够完整的，受限于我的时间，我的见解，因此也十分希望看到这的读者能贡献一份力，共同完善这份博客

如果你想联系我，请看下面，十分感谢每一位后来者，也希望在你们有能力时，提携影响后来的学弟
