# 第一部分：简单了解PCB

## **为什么要设计PCB？传统制作方式的对比**

### **刻蚀法 (Etching):** 简介、优点（成本低，即时性）、缺点（精度低，污染，不适用于批量和多层板）。——电赛的时候实在是没有办法了就使用刻蚀。

### **手工焊接电路板 (Prototyping):** 简介、优点（灵活，快速验证）、缺点（可靠性差，布线杂乱，调试困难）。——验证的时候



### **绘制/设计PCB (Modern PCB Design):** 优势（高精度，高可靠性，可批量生产，支持多层和高速信号）。——使用方便，体积小
