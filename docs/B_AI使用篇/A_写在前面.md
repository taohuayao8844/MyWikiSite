# 写在前面

## 为什么开 AI 使用篇这个板块

在现在这个 AI 的时代，大家都活在一种 AI 的焦虑当中——感觉 AI 好像被吹得很神，但是自己用起来却感觉 AI 笨笨的。可能你接触的都是豆包、Kimi，然后看到昂贵的 API 费用又望而却步，觉得没有性价比。如果你也是这样的话，那可能是你活在信息茧房里面了。

**开这个板块是希望你可以快速、高效地学会如何使用 AI，让你从 "AI 能帮我做什么" 的迷茫中走出来，真正掌握驾驭 AI 的能力。**

## 这个板块能学到什么

本系列将从入门到进阶，带你系统掌握 AI 使用的核心技能：

| 模块 | 内容 | 难度 |
|------|------|------|
| 基础认知 | API 是什么、常见的 AI 使用方式对比 | ⭐ |
| 工具搭建 | Cherry Studio 等 API 聚合平台配置 | ⭐⭐ |
| 提示词工程 | 结构化提示词编写、角色设定、上下文管理 | ⭐⭐ |
| 效率提升 | Skill（技能）配置、自定义工作流 | ⭐⭐⭐ |

## 适合人群

- ✅ 想要高效使用 AI 提升工作效率的学生党
- ✅ 对 AI 感兴趣但不知道从何入手的初学者
- ✅ 希望深入了解 AI 能力边界的高级用户
- ✅ 需要批量使用 AI API 的开发者

## 学习前提

- 📌 会基本的电脑操作
- 📌 有强烈的学习意愿（这个最重要！）
- 📌 愿意动手实践（看十遍不如做一遍）

## 开始之前

建议按顺序学习本板块的文档，从了解 AI 的基本使用方式开始，逐步深入到提示词工程和 API 配置。如果你在学习过程中遇到问题，欢迎留言交流！
