# 友链维护指南

## 概述

本站使用自定义的友链页面，支持分类、响应式设计和深色/浅色主题切换。

## 如何添加友链

### 1. 编辑友链数据文件

友链数据存储在 `src/pages/friends.js` 文件中，找到 `friendsData` 数组：

```javascript
const friendsData = [
  {
    name: '网站名称',
    description: '网站简短描述',
    url: 'https://example.com',
    category: '技术博客'  // 分类名称
  },
  // 添加更多友链...
];
```

### 2. 添加新的友链

在 `friendsData` 数组中添加新的对象，每个友链需要包含以下字段：

- **name** (必填): 网站名称
- **description** (必填): 网站简短描述（建议 50 字以内）
- **url** (必填): 网站链接
- **category** (必填): 分类名称

### 3. 添加新分类

如果需要添加新的分类，在 `categories` 数组中添加：

```javascript
const categories = [
  '全部',
  '技术博客',
  '学习资源',
  '个人主页',
  '你的新分类',  // 添加新分类
];
```

### 4. 示例

添加一个技术博客友链：

```javascript
{
  name: '前端精选',
  description: '分享前端开发技术和最佳实践',
  url: 'https://frontend-example.com',
  category: '技术博客'
}
```

## 友链页面访问

友链页面路径：`/friends`

导航栏中会自动显示"友链"入口，点击即可访问。

## 设计特点

- **响应式设计**: 自动适配桌面、平板、手机等不同设备
- **主题适配**: 支持深色/浅色主题，自动切换样式
- **分类筛选**: 点击分类标签可快速筛选友链
- **卡片交互**: 鼠标悬停显示动画效果
- **滚动优化**: 分类标签支持横向滚动

## 注意事项

1. **链接有效性**: 定期检查友链链接是否有效
2. **内容质量**: 只添加有价值和高质量的友链
3. **分类合理**: 确保分类名称准确反映网站性质
4. **描述简洁**: 描述文字尽量简短，一般不超过 50 字
5. **HTTPS**: 优先使用 HTTPS 协议的链接

## 常见问题

### Q: 为什么我的友链没有显示？
A: 请检查：
- `friendsData` 数组中的数据格式是否正确
- 分类名称是否与 `categories` 数组中的名称一致
- URL 是否以 http:// 或 https:// 开头

### Q: 如何删除友链？
A: 直接在 `friendsData` 数组中删除对应的对象即可

### Q: 如何修改友链顺序？
A: 在 `friendsData` 数组中调整对象的顺序即可

### Q: 分类标签太多怎么办？
A: 分类标签支持横向滚动，用户可以左右滑动查看所有分类
