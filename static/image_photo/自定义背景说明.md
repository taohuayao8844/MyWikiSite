# 自定义背景图片使用说明

## 如何更换个人主页背景图片

### 步骤

1. **准备背景图片**
   - 选择一张高质量的照片作为背景
   - 建议分辨率：1920x1080 或更高
   - 建议格式：JPG 或 PNG

2. **重命名文件**
   - 将图片重命名为 `background.jpg`
   - （必须是这个文件名，否则无法识别）

3. **上传图片**
   - 将 `background.jpg` 放入此目录：`static/image_photo/background.jpg`
   - 完整路径：`E:\Doc_Log\BlogBok\static\image_photo\background.jpg`

4. **刷新页面**
   - 保存文件后，刷新浏览器
   - 背景图片会自动显示，透明度已设置为 15%

### 背景图片效果

- **透明度**：15%（确保内容仍然清晰可见）
- **位置**：居中裁剪
- **覆盖方式**：全屏覆盖

### 推荐的背景图片类型

- 风景照片（山脉、森林、海滩）
- 城市天际线
- 抽象艺术
- 自然纹理（云彩、星空）

### 注意事项

- 如果没有上传 `background.jpg`，会使用默认的银色渐变背景
- 背景图片会自动适应不同屏幕尺寸
- 透明度在 CSS 中固定为 15%，如需修改，请编辑 `src/pages/index.module.css` 文件中的 `opacity: 0.15` 值

### 调整透明度

如果想要调整背景图片的透明度：

1. 打开文件：`src/pages/index.module.css`
2. 搜索 `.homeContainer::before`
3. 修改 `opacity: 0.15;` 中的数值
   - 范围：0.0（完全透明）到 1.0（完全不透明）
   - 推荐值：0.1 - 0.2

### 示例代码位置

```css
.homeContainer::before {
  content: '';
  position: absolute;
  top: 0;
  left: 0;
  right: 0;
  bottom: 0;
  background-image: url('/image_photo/background.jpg');  /* 背景图片路径 */
  background-size: cover;
  background-position: center;
  background-repeat: no-repeat;
  opacity: 0.15;  /* 透明度，可以调整这个值 */
  z-index: 0;
  pointer-events: none;
}
